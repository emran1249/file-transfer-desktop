How it works

1
ফোনে File Transfer অ্যাপ খুলুনOpen File Transfer on your phone Google Play থেকে ফ্রি ডাউনলোড করা যায় (নিচে লিংক)।It's free on Google Play (link below).
2
একই Wi-Fi তে: "FTP সার্ভার চালু করুন" চাপুনSame Wi-Fi: tap "Start FTP Server" পিসির অ্যাপের বাম পাশে আপনার ফোনের নাম চলে আসবে — ক্লিক করলেই কানেক্ট। Your phone appears on the left of the PC app — click it to connect.
3
অন্য জায়গায়/মোবাইল ডাটাতে: "Internet transfer"Anywhere / mobile data: "Internet transfer" একটি কোড বা QR শেয়ার করুন, উত্তর কোড দিন — ফাইল সরাসরি যাবে, কোনো সার্ভারে জমা হবে না। Share a code or QR, enter the reply code — files go directly, never stored on a server.

FAQ

"Windows protected your PC" দেখালে কী করব?Windows says "Windows protected your PC"

অ্যাপটি নতুন এবং এখনো ডিজিটাল সাইন করা হয়নি, তাই SmartScreen সতর্ক করে। More info → Run anyway চাপুন। ফাইলটি শুধু এই পেজের GitHub লিংক থেকে নামাবেন।

The app is new and not code-signed yet, so SmartScreen warns. Click More info → Run anyway. Only download it from the GitHub links on this page.

ফোন খুঁজে পাচ্ছে নাThe PC can't find my phone

প্রথমবার অ্যাপ খুললে Windows Firewall অনুমতি চাইলে Private networks এ Allow দিন। ফোন আর পিসি একই Wi-Fi তে আছে কিনা দেখুন, অথবা "Connect by address" দিয়ে ফোনের ঠিকানা লিখুন।

When Windows Firewall asks on first launch, allow it on Private networks. Make sure both are on the same Wi-Fi, or use "Connect by address" with the address shown on the phone.
